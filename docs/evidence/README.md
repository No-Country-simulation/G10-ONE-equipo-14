# Evidencias de etapas

Esta carpeta contiene capturas y resultados que demuestran el cierre de cada etapa del roadmap.

## Reglas

- Crear una subcarpeta por etapa siguiendo `docs/ROADMAP_ETAPAS.md`.
- Usar nombres ordenados y descriptivos.
- No incluir `.env`, tokens, claves, credenciales, direcciones privadas ni datos personales.
- Preferir datos de demostración.
- Adjuntar las evidencias finales también al issue, PR y ticket Jira relacionados.
- Actualizar o reemplazar imágenes obsoletas cuando cambie el recorrido demostrado.

No se deben almacenar aquí dumps de base de datos, logs completos ni archivos que contengan secretos.
